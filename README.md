# 🚗 TF Centro Automotriz

Un sistema integral para la gestión de talleres automotrices, reportes técnicos e inventario de repuestos. Este proyecto está dividido en una aplicación móvil para los usuarios/mecánicos y una API robusta que gestiona la lógica de negocio y el almacenamiento en la nube.

## 🛠️ Tecnologías Utilizadas

**Aplicación Móvil (Frontend):**
*   **Framework:** Flutter (Dart)
*   **Arquitectura/Patrón:** Provider, Bloc, Riverpod.

**Servidor (Backend):**
*   **Framework:** FastAPI (Python)
*   **Base de Datos:** PostgreSQL
*   **Almacenamiento de Imágenes:** Cloudinary
*   **Gestión de Correos:** Resend + Amazon SES

---

## 📂 Estructura del Proyecto

El repositorio está dividido en dos carpetas principales para mantener el código ordenado y separado:

*   `/Backend`: Contiene todo el código de la API en Python, los modelos de la base de datos y las configuraciones de servicios en la nube.
*   `/Mobile`: Contiene el proyecto en Flutter, las pantallas de la interfaz gráfica y la lógica de consumo de la API.
